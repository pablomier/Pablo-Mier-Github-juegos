# Camino al C1

Aplicación web para aprender inglés, de B1 a C1, pensada para el móvil.

- **Palabras**: 90 tarjetas (B1, B2 y C1) con repaso espaciado.
- **Gramática**: 11 temas con explicación en español y preguntas.
- **Frases**: dictado con voz del navegador y traducción al inglés.
- **Escribir**: temas de redacción por nivel, con contador de palabras.

Es un solo archivo, `index.html`, sin dependencias. Ábrelo en el navegador o publícalo con GitHub Pages. El progreso se guarda en el propio navegador.
