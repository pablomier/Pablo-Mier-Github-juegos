# Camino al C1

Aplicación web para aprender inglés, de B1 a C1, pensada para el móvil.

- **Niveles**: se empieza en B1. B2 y C1 están ocultos y se desbloquean al llegar al 80 % del nivel anterior.
- **Palabras**: 140 tarjetas (80 de B1) con repaso espaciado.
- **Gramática**: 15 temas con explicación en español y preguntas.
- **Frases**: dictado con voz del navegador y traducción al inglés.
- **Escribir**: temas de redacción por nivel. Dentro de Claude, el botón «Corregir mi texto» marca cada error y lo explica en español. Fuera de Claude (por ejemplo en GitHub Pages) se copia el texto para pegarlo en el chat.

Es un solo archivo, `index.html`, sin dependencias. El progreso se guarda en el propio navegador.
